# Overview

The **Overview** shows trends over many days, with one bar (or point) per day. Use it to see whether your AHI, leaks, pressure and usage are improving or getting worse. Open it with the **Overview** button on the left, *View → View Overview*, or <kbd>F6</kbd>.

[[idx:Overview]]

## Choosing the date range {.noindex}

[[idx:Date range!Overview]]
| Control | What it does |
|---|---|
| **Range** | Quick choices such as last week, last two weeks, last month, last 3 or 6 months, last year, everything, or a custom range. |
| **Start** / **End** | The first and last day shown, for a custom range. |
| Reset button | Returns the graphs to the selected range after you have zoomed in. |

Showing *Everything* with several years of data can take a little while.

## The graphs {.noindex}

[[idx:Usage graph]] [[idx:AHI graph!Overview]]
Each graph shows one daily figure. Common ones are:

| Graph | Shows |
|---|---|
| AHI | Events per hour each night, split by event type |
| Usage | Hours of use each night, with your [compliance](preferences.md#clinical-tab) threshold |
| Session Times | When each session started and ended |
| Pressure | Pressure statistics each night |
| Leaks | Leak statistics each night |
| Peak AHI | The worst hour each night |
| SpO2, Pulse | Oximetry statistics |
| Weight, BMI, Feelings | From your journal |

Hover over a bar to see the day's values. Double-click a bar to open that day in the [Daily view](daily.md).

- The graph drop-down at the bottom shows or hides graphs.
- **Layout** saves and restores graph arrangements.
- **Hint** shows the graph controls.
- *Overview Linecharts* in [Preferences → Appearance](preferences.md#graph-settings) chooses between **Bar Tops** and **Line Chart** for line-style graphs.

See [Working with graphs](graphs.md) for zooming, moving and pinning.
