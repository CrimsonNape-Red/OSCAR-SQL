# User Resources

Material for people who use OSCAR. Developer working notes are in `Notes/`.

| Folder | What's there |
|---|---|
| `Getting Started/` | An introduction to OSCAR 2.0. |
| `Usage/` | Notes on specific features: time corrections and restoring a profile. |
| `Data Access/` | Reading your own OSCAR data from Python: a waveform demo, a script that reproduces the 1.7.1 CSV exports, and notes on both. |
| `Sharing Data/` | Services you can use to share CPAP data or download links. |
