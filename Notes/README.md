# Notes

Working notes for people developing OSCAR. If you use OSCAR and are looking for help, see
`UserResources/` and the User Guide instead.

This folder is part of the public repository. Never put serial numbers, personal names or
sample-data identifiers in it.

| Folder | What's there |
|---|---|
| `Guides/` | How parts of OSCAR work today: architecture, the new-developer guide, subsystem how-tos. `OSCAR 1.x Files/` covers the file formats OSCAR 1.x wrote. |
| `Database/` | Schema reference, ER diagram, data dictionary and ready-made SQL. |
| `Formats/` | Machine data formats, one folder per manufacturer. `_General/` holds the SD card fingerprints and loader detection patterns. |
| `Design/` | Design specs and implementation plans, mostly dated. `UI/` holds the interface redesign; `Archive/` holds superseded versions. |
| `Investigations/` | One-off analyses, code reviews and measurements. |
| `Process/` | The bug fix log (`BUG_FIXES.md`), Git how-tos, maintenance notes and AI aids. |
| `Wiki/` | A backup of the user-facing wiki pages. |
